# Deploy SurakshaSathi on Render (free tier if available)

This repository includes `render.yaml` so Render can read the service configuration as a Blueprint.

## Steps requiring your account
1. Upload the contents of this project folder to a GitHub repository. Keep it private if you prefer.
2. In Render, choose **New → Blueprint**, connect that repository, and apply the Blueprint.
3. Wait for the first deploy, then open the public `onrender.com` URL Render assigns.
4. Verify `/`, `/health`, and `/docs`.

## Important limitations and safety
- The Blueprint uses `DEMO_MODE=1` so the demo interface can be tried. Demo endpoints are public and rate-limited; use only synthetic/sample information. Do not submit real people's private or sensitive data.
- `ADMIN_TOKEN` is generated by Render. Do not publish it or put it in source control.
- `WHATSAPP_PROVIDER=console` does not send real WhatsApp messages.
- The free service filesystem is ephemeral. SQLite data and generated audio may disappear after a restart or redeploy. This is a demo deployment, not durable production hosting.
- Before using real users' data or real messaging, disable public demo endpoints, configure durable storage, review access controls and privacy/security, and configure a legitimate messaging provider.
- Do not commit `.env`, API keys, passwords, or database/audio files.
